<b>Overview<br>
This project demonstrates a one-to-one relationship between User and Profile entities. Each user has exactly one profile, and each profile is associated with one user. The relationship is implemented using JPA or Hibernate.
<br><br>
Features</b><br>
Create and manage User and Profile entities.
Establish and persist one-to-one relationships between users and profiles.
Fetch and display user details along with their profile.
